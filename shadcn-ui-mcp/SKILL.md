# Skill: shadcn-ui-mcp-server

## Descrição
Use esta skill quando o usuário pedir para criar, editar ou instalar componentes de interface usando shadcn/ui via MCP server. Cobre geração de componentes, customização de temas e integração com projetos React/Next.js que usam shadcn/ui.

## Quando usar
- Pedidos de UI components (botões, cards, modais, forms, etc.) usando shadcn/ui
- Configuração inicial do shadcn/ui num projeto
- Customização de tokens de design (cores, espaçamento, tipografia) dentro do shadcn/ui

## Repositório de referência
https://github.com/Jpisnice/shadcn-ui-mcp-server

## Instruções
1. Verificar se o MCP server está conectado antes de tentar gerar componentes.
2. Sempre usar os componentes shadcn/ui como base, não recriar do zero.
3. Seguir os design tokens já definidos no projeto do usuário.
