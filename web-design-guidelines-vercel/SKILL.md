# Skill: web-design-guidelines-vercel

## Descrição
Use esta skill como referência de boas práticas de interface web, baseada nas diretrizes de design da Vercel. Cobre performance percebida, acessibilidade, microinterações e clareza visual.

## Quando usar
- Revisão de UI já construída
- Definição de padrões de qualidade antes de entregar um projeto
- Dúvidas sobre "isso está bom o suficiente visualmente?"

## Referência
https://vercel.com/design (Vercel Web Interface Guidelines)

## Instruções
1. Verificar contraste, tamanho de fonte e área de toque (mobile-first).
2. Garantir feedback visual em toda ação (hover, loading, erro, sucesso).
3. Preferir clareza a excesso de estilo — reduzir ruído visual.
4. Testar sempre em mobile antes de considerar finalizado.
