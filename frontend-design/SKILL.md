# Skill: frontend-design

## Descrição
Use esta skill sempre que for criar ou redesenhar qualquer UI (landing pages, componentes, dashboards). Garante decisões de design intencionais em vez de padrões genéricos — tipografia, hierarquia visual, espaçamento e direção estética.

## Quando usar
- Criação de landing pages, sites ou componentes visuais
- Redesign de UI existente
- Qualquer tarefa onde a estética final importa (não só a funcionalidade)

## Instruções
1. Evitar escolhas "default" de framework (ex: cores padrão do Tailwind sem propósito).
2. Definir uma direção estética clara antes de codar (minimalista, bold, editorial, etc.).
3. Manter consistência tipográfica e de espaçamento em todo o projeto.
4. Priorizar hierarquia visual clara: o que o usuário deve ver primeiro, segundo, terceiro.
