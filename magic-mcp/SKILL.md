# Skill: magic-mcp

## Descrição
Use esta skill quando o usuário pedir geração rápida de componentes de UI a partir de descrições em linguagem natural, usando o Magic MCP da 21st.dev.

## Quando usar
- Pedidos como "crie um componente de [X]" sem especificação técnica detalhada
- Prototipagem rápida de interfaces
- Geração de variações visuais de um mesmo componente

## Repositório de referência
https://github.com/21st-dev/magic-mcp

## Instruções
1. Priorizar geração rápida sobre perfeição — é uma ferramenta de prototipagem.
2. Sempre revisar o código gerado antes de integrar ao projeto final.
3. Combinar com a skill de frontend-design para manter consistência visual.
