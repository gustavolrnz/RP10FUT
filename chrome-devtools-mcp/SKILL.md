# Skill: chrome-devtools-mcp

## Descrição
Use esta skill quando for necessário inspecionar, depurar ou testar uma página web diretamente no navegador via MCP — performance, erros de console, estrutura DOM, requests de rede.

## Quando usar
- Depuração de bugs visuais ou funcionais numa página real
- Análise de performance (carregamento, requests lentos)
- Verificação de responsividade e comportamento em diferentes telas

## Instruções
1. Sempre inspecionar o console de erros antes de qualquer outra análise.
2. Verificar requests de rede quando houver suspeita de dado não carregando.
3. Usar o inspetor de elementos para confirmar problemas de CSS/layout antes de propor correção.
